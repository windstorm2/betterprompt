How the score works

Original weights: clarity 20, accuracy 20, sources 20, verification 20, efficiency 10, output 10. For quick tasks, sources and independent verification may be marked not applicable; the remaining applicable scores are normalized to 100. Checks look for explicit wording and contextual clues, so the score is approximate and can miss implied intent, irony, negation, or unusual phrasing.

Privacy and limitations

Everything runs inside this HTML file, even without an internet connection. The tool does not send, save, or log your prompts; refreshing the page clears them. The approximate token count uses character length and is not an API billing measurement.

Evaluating actual answer accuracy requires source checking and/or independent review after the AI answers. A high prompt score cannot ensure the model follows instructions. Suitable for prompt preparation, not for fact verification.
